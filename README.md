# ft_linear_regression

A from-scratch implementation of **simple linear regression** trained with **batch gradient descent**, built for the 42 school project.

No `sklearn`, no `numpy.polyfit`, no closed-form solver — only the update rule from the subject PDF.

---

## How it works (one paragraph)

We assume car price is a linear function of mileage: `price ≈ θ0 + θ1 × mileage`.  
We measure how wrong a candidate line is with **mean squared error** `J`.  
Starting at θ = 0, we repeatedly subtract `α × (average residual)` from each θ — that is **batch gradient descent** and matches the subject's `tmpθ` formulas.  
Because raw km (~10⁵) would make tmpθ1 enormous, we **min-max scale mileage to [0, 1]** during training, then algebraically convert θ back so `predict.py` still uses the plain formula `θ0 + θ1 × raw_km`.  
We save θ to `thetas.json`. Before training, that file is absent and the estimate is 0.

## Usage

### 1. Train

```bash
python train.py
```

Runs 10 000 iterations of batch gradient descent with `α = 0.5` and saves `thetas.json`.

Optional flags:

```bash
python train.py --lr 0.1 --iters 5000
```

| Flag | Default | Meaning |
|------|---------|---------|
| `--lr` | `0.5` | Learning rate (α) |
| `--iters` | `10000` | Number of GD iterations |

Expected output (values may differ slightly):

```
theta0 =  8499.599650
theta1 =    -0.021449
theta1 is negative -- correct (more km = lower price).
Thetas saved to: .../thetas.json
```

### 2. Predict

```bash
python predict.py
```

Prompts for a mileage and prints the estimated price.  
If `train.py` has never been run, `thetas.json` is missing → both θ are 0 → estimate is **0** (subject requirement).

```
Mileage (km): 100000
Estimated price: 6354.703...
```

### 3. Plot (bonus)

```bash
python plot.py
```

Displays a scatter of all 24 cars with the regression line overlaid. Also saves `plot.png`.

### 4. Precision (bonus)

```bash
python precision.py
```

Prints MAE, MSE, RMSE, and R² on the training set.

```
MAE  : 557.84
RMSE : 667.57
R²   : 0.7330  (line explains 73 % of price variance)
```

## Edge cases handled

| Situation | Behavior |
|-----------|----------|
| `predict.py` before `train.py` | θ = 0, estimate = 0 (subject requirement) |
| `data.csv` missing | `FileNotFoundError` with a clear message |
| Empty CSV (`m = 0`) | `ValueError` — cannot divide by m |
| Non-numeric cell in CSV | `ValueError` with the line number |
| User types `abc` as mileage | Rejected with a message; asks again |
| Empty mileage input | Rejected; asks again |
| All mileages equal (σ = 0) | `ValueError` in `min_max_bounds` — degenerate data |
| Negative mileage | Accepted — the linear model is unbounded; price may be negative |
| α too large (`--lr 10`) | J explodes (visible in the printed log); retrain with smaller α |

## Algorithm summary

```
Hypothesis:   h(x) = θ0 + θ1 × x

Cost:         J = (1/2m) Σ (h(x⁽ⁱ⁾) - y⁽ⁱ⁾)²

Update (simultaneous):
    tmp0 = α × (1/m) × Σ (h(x⁽ⁱ⁾) - y⁽ⁱ⁾)
    tmp1 = α × (1/m) × Σ (h(x⁽ⁱ⁾) - y⁽ⁱ⁾) × x⁽ⁱ⁾
    θ0 ← θ0 - tmp0
    θ1 ← θ1 - tmp1

Feature scaling (min-max):
    x' = (x - xmin) / (xmax - xmin)   →   x' ∈ [0, 1]

Denormalize back to raw km:
    θ1 = θ1' / span
    θ0 = θ0' - θ1' × xmin / span
```
